# VYRO (sonicteam)
Android app: Kotlin + Jetpack Compose + Supabase. Phase 1 in progress.
Build: push to main, then download the APK from the GitHub Actions run (artifact: vyro-debug-apk).
Supabase: for testing, turn off "Confirm email" in Auth settings, or confirm via the email link.
Never commit a secret / service_role key.
